OSI (open system interconnection) model (it describes the process or path a data takes to travel from one computer to another)

APPLICATION LAYER --------->the browser, https, etc,......

PRESENTATION LAYER--------->application encryption like SSL / TLS

SESSION LAYER-------------->control protocols, tunneling protocols

TRANSPORT LAYER------------>tcp segment, udp datagram

NETWORK LAYER-------------->ip address, router, packet

DATA LINK LAYER------------> MAC addresses, Frames, extended unique identifiers 

PHYSICAL LAYER-------------> Cables , fibres , signals
