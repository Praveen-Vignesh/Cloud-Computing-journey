# OSI Model

The **OSI (Open Systems Interconnection) model** describes the path data
takes to travel from one computer to another, broken into 7 layers.

| # | Layer | What lives here |
|---|-------|-----------------|
| 7 | **Application** | The browser, HTTP/HTTPS, etc. |
| 6 | **Presentation** | Application encryption — SSL / TLS |
| 5 | **Session** | Control protocols, tunneling protocols |
| 4 | **Transport** | TCP segments, UDP datagrams |
| 3 | **Network** | IP addresses, routers, packets |
| 2 | **Data Link** | MAC addresses, frames, EUIs |
| 1 | **Physical** | Cables, fibres, signals |
